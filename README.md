# Banana Books Dashboard

A mobile-first content strategy dashboard for Banana Books, designed for a social media manager tracking TikTok performance for YA fiction and graphic novels.

## Features
- Yellow and orange gradient visual system with a clean, airy card layout
- Mobile-first dashboard optimized for on-the-go use
- Date-range controls for 7D, 30D, and 90D views
- KPI cards for content views, engagement rate, ad revenue, and churn
- Audience insights, prime posting times, and trending content ideas
- Fully static project ready for Vercel deployment

## Tech
- Vite static site
- Vanilla HTML, CSS, and JavaScript
- Google Lato font

## Run locally
```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open http://localhost:5173.

## Build for production
```bash
npm run build
```
