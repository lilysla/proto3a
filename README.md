# Banana Books Content Studio

A tablet-first content strategy dashboard for Banana Books, designed for a social media manager tracking TikTok performance for YA fiction and graphic novels.

## Features
- Yellow and orange gradient visual system with a clean, airy card layout
- Responsive dashboard optimized for tablet use
- Date-range controls for 7D, 30D, and 90D views
- KPI cards for content views, engagement rate, ad revenue, and churn
- Audience insights, prime posting times, and trending content ideas
- Vue 3 + Vite static project ready for Vercel deployment

## Tech
- Vue 3
- Vite
- Vercel static hosting
- Google Lato font

## Run locally
```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open http://localhost:5173.

## Build for production
```bash
npm run build
```

The production output is written to `dist/`. Vercel uses `vercel.json` to serve the Vue app for direct routes.
